DESKRIPSI SINGKAT

FitTrack adalah gym kecil dengan sekitar 150 member aktif. Selama ini datanya dicatat di buku tulis, sehingga mudah tercecer dan sulit dicari. Program Java ini adalah langkah awal digitalisasi: data member disimpan selama program berjalan, dan setiap data yang masuk diperiksa dulu supaya kesalahan seperti nomor telepon yang salah format tidak lolos.

FITUR UTAMA

1.	Menyimpan data member: nama, nomor telepon, tanggal daftar, dan jenis paket.
2.	Menolak nama yang kosong atau hanya berisi spasi.
3.	Menolak nomor telepon yang tidak diawali angka 0, berisi selain angka, atau kurang dari 10 digit.
4.	Menolak jenis paket selain Basic, Premium, dan VIP.
5.	Menampilkan alasan penolakan yang jelas, dan nilai lama tetap dipertahankan.
6.	Membuat member tanpa memilih paket (otomatis Basic).
7.	Tetap membuat data member dengan nilai default saat ada data yang tidak valid.
8.	Menampilkan seluruh daftar member dengan format rapi dan berlabel.
